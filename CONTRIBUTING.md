# Contributing to openLoadstar

> 🚧 The English version is in preparation.
> Please refer to **[CONTRIBUTING.ko.md](CONTRIBUTING.ko.md)** for the full guide.

## Quick Overview

- 🐛 **Bug reports & feature requests**: open an [Issue](https://github.com/openLoadstar/openLoadstar/issues) on the relevant component repo
- 💬 **Larger ideas / discussions**: start a thread in [Discussions](https://github.com/openLoadstar/openLoadstar/discussions) first
- 🔧 **Code contributions**: fork → topic branch → tests → PR
- 📝 **Commit style**: [Conventional Commits](https://www.conventionalcommits.org/) (e.g. `feat(cli): add --recent flag`)
- 📄 **License**: contributions are licensed under [Apache-2.0](./LICENSE)

By contributing, you agree that your contributions will be licensed under the Apache-2.0 license.
