## Quick Reporting

If you have found a security vulnerability, **please do not open a public issue.**
Use one of the private channels below:

1. **GitHub Security Advisories** (preferred):
   https://github.com/openLoadstar/openLoadstar/security/advisories/new
2. **Maintainer**: [@aeolusk](https://github.com/aeolusk) (via GitHub profile contact)

We will acknowledge your report within **48 hours** and provide a status update within **7 days**.
